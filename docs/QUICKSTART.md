# Quick start

1. Install locked dependencies in the repository root and build H5/Mini with your own HTTPS API endpoints and Mini AppID.
2. In `installer/yhtctl/`, run `npm ci`; use `installer/skill/SKILL.md` as the operator workflow.
3. Do not treat the withheld website or community runtime archive as part of this public payload. A successful build or HTTP response is not production or business acceptance.
