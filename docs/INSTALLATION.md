可直接下载经过校验的社区安装包：

- 安装包：<https://yeeco.oss-cn-chengdu.aliyuncs.com/open-source/contract-pro/releases/2.0.0/yihetong-installer-2.0.0-vnext-20260830-community.zip>
- SHA-256：<https://yeeco.oss-cn-chengdu.aliyuncs.com/open-source/contract-pro/releases/2.0.0/ARTIFACT_SHA256SUMS.txt>
- 制品清单：<https://yeeco.oss-cn-chengdu.aliyuncs.com/open-source/contract-pro/releases/2.0.0/ARTIFACT_MANIFEST.json>
- 部署手册：<https://yeeco.oss-cn-chengdu.aliyuncs.com/open-source/contract-pro/releases/2.0.0/Contract.Pro-%E7%B3%BB%E7%BB%9F%E9%83%A8%E7%BD%B2%E6%89%8B%E5%86%8C.pdf>

安装包支持 Windows 10/11 + WSL2 Ubuntu、Ubuntu 22.04/24.04 和 Rocky Linux 9。部署不限定云厂商，也不要求使用 Agent 或阿里云 RAM。先核对 SHA-256，再按照包内手册生成自己的非秘密配置，并通过受保护引用提供密码、密钥和证书。
