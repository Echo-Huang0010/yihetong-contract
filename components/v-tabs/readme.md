# v-tabs

uni-app 标签页组件，支持滚动、平铺、胶囊样式、固定定位及对象数组字段映射。

```vue
<v-tabs v-model="current" :tabs="tabs" @change="changeTab" />
```

常用参数包括 `scroll`、`height`、`lineColor`、`pills`、`field`、`fixed` 和 `paddingItem`；`change` 事件返回选中索引。
